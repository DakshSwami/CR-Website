## CR Website
This is a sample website for the Camer Racing Team, it consists of the following pages.
1. Landing page.
2. About Us page.
3. The Paddock page.

I have utilized Boothstrap Framework for majority of the formatting and responsive design of the website along with some minor changes in my own CSS files.

This website follows a red and black theme to match the latest car of built by the team. The navbar and the footer stays constant throughout the website with links to the other pages.
